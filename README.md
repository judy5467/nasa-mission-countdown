# NASA Mission Countdown

## Project idea
The page enables users to see how many days, minutes, hours and seconds are left until an upcoming NASA launch. Most people do not know when missions launch, this idea could help then visually see. 
## Technologies used
- HTML for the page structure
- CSS for the styling
- JavaScript for the countdown logic
- Git and GitHub for version control and project management

## How to run
1. Click the green **Code** button on this repository and choose **Download ZIP**.
2. Unzip the folder on your computer.
3. Double-click `index.html` to open it in your web browser.
4. The countdown starts automatically.
