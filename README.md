# NASA Mission Countdown

## Project idea
The page enables users to see how many days, minutes, hours and seconds are left until an upcoming NASA launch. Most people do not know when missions launch, this idea could help them see it visually.
## Technologies used
- Markdown for the documents
- GitHub Issues for task tracking
- Git branches and pull requests for managing changes
## How to use
1. Open the `docs` folder in this repository.
2. Read `project-plan.md` for the goals, planned features and timeline.
3. Read `mission-info.md` for the mission the countdown is based on.
4. Check the Issues tab to see how the work was planned and tracked.
